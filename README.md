Medical Health Mobile App — адамдарға өз денсаулығын бақылауға көмектесетін мобильді қосымша. 
Қосымша арқылы денсаулық туралы ақпаратты көруге, дәрігерге жазылуға, дәрі қабылдау уақытын 
бақылауға және медициналық мәліметтерді сақтауға болады. Оның мақсаты — медициналық қызметтерді 
қолжетімді етіп, адамдардың денсаулығына жауапкершілікпен қарауына көмектесу
